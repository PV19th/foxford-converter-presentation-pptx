# Конвертер презентаций Фоксфорда

Внутренний сайт: методист загружает старую презентацию урока (.pptx), выбирает шаблон, класс и номер урока и получает файл в новом шаблоне «Сегмент 5–11», превью слайдов и памятку, что проверить вручную.

Статус: конвертер работает в Docker из командной строки (этап 3). Сайт — следующий этап.

## Что где лежит

- `converter/` — отлаженный конвертер. Логику не менять (см. `CLAUDE.md`). `fix_*.py` — примеры ручной доводки, сайтом не используются.
- `app/pipeline.py` — обработка одной презентации: конвертация → сжатие → сверка текста → превью → памятка.
- `templates/<шаблон>/profile.json` — настройки шаблона: базы и слайды-доноры для каждого класса.
- `base/` — базовые презентации (`ex58`, `ex64`) и фирменный шаблон `template_4x3_v01_26.pptx` (сжат `tools/compress_template.py`).
- `tests/` — прогон тестовых презентаций и отпечатки эталонных результатов (`tests/baseline/`).
- `docs/` — README конвертера, чек-лист правок, отчёты по переносам, карта шаблона.

## Как запустить (нужен Docker)

Одна презентация:

```bash
docker compose build
docker compose run --rm -v "$PWD:/srv" app python3 -m app.pipeline "test_inputs/old/5.21 ….pptx" outputs/5.21 5.21
```

Все тестовые презентации из `test_inputs/old/` (результат — `outputs/tests/index.html`, превью рядом с эталоном):

```bash
./tests/run_all.sh
```

## Секреты

Пароли и ключи хранятся только в `.env` (не попадает в репозиторий). Образец — `.env.example`.

Тестовые презентации (`test_inputs/`) и результаты (`outputs/`) в репозиторий не попадают — это материалы уроков.

## Стикеры

Папки `assets/` нет: стикеры («ВАЖНО», «?» и др.) методисты ставят вручную. Конвертер оставляет под них место и пишет в отчёт, на какой слайд какой стикер поставить.
