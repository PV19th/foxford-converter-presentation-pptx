Конвертер Фоксфорда на вашем компьютере

Тестовая версия для небольшой группы. Это тот же конвертер, что на сайте, только работает у вас на компьютере. Интернет нужен только для кнопки «Доработать с ИИ».

1. Какой архив нужен

Mac с чипом Apple (M1, M2, M3, M4, M5)«Конвертер Фоксфорда — Mac (M1–M5)»
Mac с процессором Intel«Конвертер Фоксфорда — Mac (Intel)»
Windows 10 или 11«Конвертер Фоксфорда — Windows»

Как узнать, какой у вас Mac: меню Apple (яблоко слева вверху) → «Об этом Mac». Строка «Чип Apple M…» — первый архив, «Процессор Intel» — второй.

2. Один раз: установить Docker Desktop

Docker — программа, внутри которой работает конвертер (ему нужны Linux, LibreOffice и шрифт Open Sans).

  1. Скачайте Docker Desktop с сайта docker.com/products/docker-desktop. Для Mac выберите свой вариант: Apple Silicon (чип M) или Intel.
  2. Установите как обычную программу. На Windows установщик может попросить включить WSL 2 и перезагрузить компьютер — соглашайтесь. Для установки могут понадобиться права администратора: если их нет, обратитесь в IT.
  3. Откройте Docker Desktop. Примите условия, вход в аккаунт Docker можно пропустить (Skip). Дождитесь внизу окна надписи Engine running.

3. Запуск

  1. Распакуйте архив: на Mac — двойной щелчок, на Windows — правой кнопкой по архиву → «Извлечь всё…» (двойной щелчок на Windows только открывает архив, но не распаковывает). Папку можно положить куда угодно, например в «Документы». Не запускайте файлы прямо из архива.
  2. Дважды щёлкните «Запустить». Откроется окно с сообщениями. В первый раз конвертер устанавливается в Docker 1–3 минуты.
  3. В браузере откроется конвертер: http://localhost:8765. Пароль не нужен. Адрес можно добавить в закладки.

Mac, первый запуск. macOS скажет, что не может проверить разработчика. Нажмите «Готово», откройте «Системные настройки» → «Конфиденциальность и безопасность», внизу нажмите «Всё равно открыть» и подтвердите паролем от Mac. Так нужно сделать один раз для каждого из трёх файлов.

Если кнопки «Всё равно открыть» нет (её могло отключить IT): откройте программу «Терминал», перетащите в её окно файл «Запустить.command» и нажмите Enter. Так же — с «Остановить» и «Лог для автора».

Windows, первый запуск. Если появится синее окно «Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Если спросит «Запустить этот файл?» — нажмите «Запустить».

4. Каждый день

  • Начинаете работу — «Запустить». Он сам включит Docker, если тот выключен, и откроет конвертер в браузере.
  • Закончили — можно нажать «Остановить», чтобы освободить память компьютера. Это необязательно.
  • Готовые файлы хранятся 24 часа — скачивайте .pptx сразу.
  • Кнопка Доработать с ИИ работает, пока не исчерпан дневной лимит.

5. Новая версия

  1. Удалите старую папку конвертера.
  2. Распакуйте новый архив и нажмите «Запустить». Старая версия удалится из Docker сама.

Номер версии — в названии папки и в первой строке окна «Запустить».

6. Если что-то не так

  • Дважды щёлкните «Лог для автора» — на рабочем столе появится файл «Конвертер Фоксфорда — лог.txt». Отправьте его автору вместе с презентацией и описанием, что пошло не так.
  • «Не найден Docker» — установите Docker Desktop (раздел 2).
  • «Docker не запустился» — откройте Docker Desktop вручную, дождитесь «Engine running» и снова нажмите «Запустить».
  • «Не найдена папка files» — архив не распакован: распакуйте его (раздел 3) и запускайте из распакованной папки.
  • Конвертер на Mac работает медленно — в Docker Desktop: Settings → Resources, дайте ему не меньше 4 ГБ памяти.
