# Сервер для конвертера презентаций — требования для IT

Составлено 30.10.2026 (копия страницы «Сервер конвертера презентаций» на claude.ai). Что изменилось после — в конце.

Внутренний сайт для методистов. Методист загружает старую презентацию урока (.pptx до 100 МБ), сайт переносит её в фирменный шаблон 4:3 или 16:9 и показывает превью слайдов с отчётом, что проверить вручную. Вход по общему паролю. Всё работает в Docker, код лежит в закрытом репозитории на GitHub.

| Процессор | Память | Диск | Система |
|---|---|---|---|
| **4 vCPU** (минимум 2) | **8 ГБ** (минимум 4) | **80 ГБ** SSD или NVMe (минимум 60) | **Ubuntu 24.04** LTS, x86_64 |

Это обычный недорогой облачный VPS, отдельное железо не нужно. Размещение: за рубежом, предпочтительно в ЕС.

## Полная конфигурация

| Параметр | Рекомендуется | Минимум |
|---|---|---|
| Процессор | 4 vCPU | 2 vCPU (урок обрабатывается дольше) |
| Оперативная память | 8 ГБ | 4 ГБ |
| Диск | 80 ГБ SSD / NVMe | 60 ГБ SSD |
| Сеть | от 100 Мбит/с | 100 Мбит/с |
| Трафик | без лимита или от 1 ТБ в месяц | 500 ГБ в месяц |
| IP-адрес | 1 публичный IPv4 | 1 публичный IPv4 |
| Операционная система | Ubuntu 24.04 LTS | Ubuntu 22.04 LTS |
| Расположение | ЕС (Нидерланды, Германия, Финляндия и т. п.) | любая страна, где доступен API Anthropic |
| Резервные копии | не нужны | код в GitHub, файлы живут сутки |

## Откуда цифры

Замерено на реальных уроках, в том числе на самом тяжёлом файле (90 МБ, 52 слайда).

| Что | Значение |
|---|---|
| Время на один урок | 20–25 с на Mac с 10 ядрами; на сервере с 2–4 vCPU — примерно 30–60 с |
| Пик памяти на задачу | около 1,2 ГБ: сайт до 0,55 ГБ плюс конвертер или LibreOffice до 0,56 ГБ |
| Очередь | строго одна задача за раз (LibreOffice нельзя запускать параллельно) — до 60–100 уроков в час |
| Диск на задачу | 100–160 МБ: исходник, результат, превью; удаляется через 24 часа |
| Задачи за сутки на диске | около 8 ГБ при 50 уроках в день |
| Образ Docker | около 0,9 ГБ, плюс кеш сборки |
| Файлы пользователя | загрузка до 100 МБ, готовый файл до 50 МБ |
| Трафик | около 150 МБ на урок; при 50 уроках в день — около 250 ГБ в месяц |

## Почему за рубежом

**ЕС — выбрано:**
- следующий этап — доработка презентаций ИИ (Claude); API Anthropic из России недоступен, из ЕС работает напрямую;
- Docker Hub, GitHub и обновления Ubuntu скачиваются без сбоев;
- из России сайт открывается обычным браузером.

**Россия:**
- нужна, только если политика компании требует хранить материалы в РФ;
- ИИ — только через прокси или другого провайдера;
- для Docker понадобится зеркало реестра.

## Сеть и доступ

- **Входящие порты:** 80 и 443 (сайт по HTTPS, бесплатный сертификат Let's Encrypt), 22 (SSH, только по ключу). Остальное закрыто файрволом.
- **Исходящие:** github.com (код), Docker Hub (образы), репозитории Ubuntu, адрес API ИИ (см. ниже).
- **Адрес сайта:** поддомен, например `converter.foxford.ru`, и DNS-запись типа A на IP сервера.
- **Размер запроса:** прокси перед сайтом должен пропускать загрузку до 100 МБ и ждать ответа несколько минут.
- **Шрифт сайта** загружается в браузере пользователя с fonts.googleapis.com.

## Данные и безопасность

- Базы данных нет. Загруженные презентации и результаты хранятся 24 часа и удаляются автоматически.
- Вход по общему паролю; позже возможен корпоративный SSO.
- Пароли и ключи — только в файле `.env` на сервере, никогда в репозитории.
- Логи — в `data/logs/` с ротацией.
- В материалах уроков бывают имена и фото преподавателей. Нужно уточнить, разрешено ли хранить их на внешнем сервере.

## Что нужно от заказчика

1. Согласовать с IT и службой безопасности размещение материалов уроков на сервере.
2. Арендовать сервер с параметрами выше: Ubuntu 24.04, публичный IPv4.
3. Выделить поддомен и создать DNS-запись типа A на IP сервера.
4. Дать доступ по SSH-ключу: публичная часть ключа добавляется в панели хостинга при создании сервера.
5. Добавить на GitHub ключ только для чтения (Settings → Deploy keys), чтобы сервер мог скачивать код.
6. Задать общий пароль для коллег и контакт для кнопки «Сообщить автору». Вписываются в `.env` на сервере.
7. Ключ ИИ и дневной лимит расходов — в `.env` (см. ниже).

## Что делается при развёртывании

- Установка Docker и Docker Compose, файрвол, HTTPS-прокси с автоматическим сертификатом.
- Запуск сайта с автоперезапуском после сбоя или перезагрузки сервера.
- Обновление одной командой: `git pull && docker compose up -d --build`.
- Инструкция для IT в `DEPLOY.md`: сборка, запуск, обновление, где логи.

Параметры рассчитаны на команду методистов и несколько десятков уроков в день. Если нагрузка вырастет, достаточно перейти на тариф с большим числом процессоров: задачи по-прежнему идут по одной, и каждая выполняется быстрее.

## Что изменилось после 30.10.2026

Решение о стране — за автором и IT; в `CLAUDE.md` пока записано «скорее всего за рубежом».

- Появились индивидуальные шаблоны преподавателей (первый — Авраменко В.). Готовый файл с фирменным или индивидуальным шаблоном весит обычно 25–35 МБ: в него попадают все макеты шаблона.
