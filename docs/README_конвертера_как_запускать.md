# Конвертер старых презентаций → новый шаблон: запуск в новом чате

Этот файл для Claude. Пользователь пишет только, какие презентации брать. Остальное делается по этой инструкции.

## 0. Прочитать перед работой
- `claude/Чек-лист переноса презентаций — разбор правок 6.4.md` — правила оформления, выведенные из правок пользователя. Большая часть уже зашита в конвертер (см. ниже), но при проверке результата и ручной доводке сверяться нужно с чек-листом.
- `claude/Перенос 5.15–5.20 — отчёт и метод.md`, `claude/Перенос 6.15–6.17 — отчёт.md`, `claude/Перенос 5.22–5.24 — отчёт.md`, `claude/Перенос 5.21 — отчёт.md` — что конвертер делает сам и что обычно приходится проверять глазами.

Как чек-лист учтён в конвертере:
- Автоматически: п. 1 (номер урока из нумерации раздела), 2 (картинки укрупняются; вокруг текста держится зазор 0,12″), 3 (блоки центрируются по вертикали), 5 (жирный > 5 слов снимается), 6 (кегль 16/14/12, пустые абзацы тоже 14/12), 7 (цветные выделения → 641FF1), 10 (подписи без заливки; подпись слева от низа картинки переносится под картинку; подпись прижимается к видимому низу изображения с учётом белого поля; широкая подпись сужается по тексту и центрируется по картинке), 11 (стрелки и скобки переносятся), 12 («ВАЖНО» ставится рядом с блоком), 13 (номера слайдов — поле slidenum заполняется номером), 14 (поля плашек с текстом 0,25 см со всех сторон — `pad_plate`; если сбоку заходит картинка или сверху лежит шапка-таблица/цветная шапка (в т. ч. начинающаяся до 0,35″ выше плашки), поле с этой стороны увеличивается).
- Частично: п. 9 — плашки-определения со значком «ВАЖНО» становятся жёлтыми, остальные плашки сохраняют цвет исходника. Персиковые резюмирующие плашки автоматически не ставятся.
- Для 5 класса (база 5.8): кегль титула не больше 40 pt (как в макете), строки заголовка не заходят на лиса с брелоком.
- Для 6 класса (база 6.4) дополнительно: слайд «Почему стоит посмотреть» (текст плашкой под заголовком, картинка/мем на всё поле), «Подумаем!» / «Работа с картой» по паттерну 3.3 (вопрос справа от заголовка, иллюстрация на всё поле, 3D-«?» слева), титул 6.4 с картинкой из старого титула в наклонной рамке, выноски донора удаляются.
- «Подведём итоги!»: строк столько, сколько номеров-стрелок в исходнике; незаполненные пункты остаются пустыми строками.
- Вручную: п. 4 (схемы на всю ширину), п. 8 (выравнивание текста в карточках влево), чередование цвета соседних схем, выбор титула «под настроение урока». Примеры скриптов ручной доводки — `claude/converter/fix_522_524.py`, `claude/converter/fix_521.py` (длинный титул в 3 строки) (правки по id/тексту фигур после convert.py).

## 1. Подготовка (каждая новая сессия)
1. Рабочая папка: `/home/claude/w` (или любая другая, её путь задаётся переменной `CONV_DIR`).
2. Скачать в неё из проекта `claude/converter/engine.py`, `convert.py`, `common.py`, `verify.py`, `shrink.py` (project_read → Write; большие файлы переписывать целиком, без правок).
3. Из подключённой папки «презы история/примеры» (лежит в ~/Downloads/презы история) взять (device_stage_files) — или из вложений, если пользователь прикрепил примеры к сообщению:
   - `5.8 Общество Древнего Египта_ фараоны, вельможи, жрецы (1).pptx` → `ex58.pptx` (база для 5 класса + значок «ВАЖНО»);
   - `6.4 Европа в IX–XI вв._новый.pptx` → `ex64.pptx` (база для 6 класса);
   - `5.3. Первобытные охотники и собиратели_новый.pptx`, откуда нужна только картинка объёмного «?».
4. Собрать `assets/`:
   - `assets/vazhno.png` = `ppt/media/image24.png` из ex58.pptx (значок «ВАЖНО»);
   - `assets/qmark.png` = картинка «?» из 5.3: слайд 12, фигура `Google Shape;185;p27`, 376×518.
5. Выполнить `apt-get update && apt-get install -y fonts-open-sans`, чтобы рендер для проверки совпадал с шаблоном.
6. Не называть свои скрипты `inspect.py` и т. п. — конфликт со стандартной библиотекой Python.

## 2. Запуск
5 класс (база 5.8): `python3 convert.py старый.pptx «<урок>_новый.pptx» 5.3`

6 класс (база 6.4 — так пользователь попросил для 6.15–6.17):
```
export CONV_BASE=/home/claude/w/ex64.pptx
export CONV_DONOR='{"title":1,"plan":3,"wait":5,"summary":16,"reflection":29,"bye":30,"links":31,"dividers":[4,17],"content":[7,7,26,7],"why":2,"think":6,"title_strip_callouts":true,"title_pic":true,"wait_step":1.34,"wait_center":4.18}'
python3 convert.py старый.pptx новый.pptx 6.15
```
Номер вида `6.15` задаёт тег «6 класс» и «Урок 15».

## 3. После сборки (обязательно)
- `python3 verify.py старый.pptx новый.pptx` — сверка слов. Расхождений быть не должно, кроме служебных кнопок старого шаблона и склейки слов, разбитых в исходнике на части.
- Отрендерить слайды (`soffice → pdf → pdftoppm`, контакт-лист; soffice не запускать параллельно) и просмотреть все слайды по чек-листу. Особенно проверить схемы со стрелками, таблицы и слайды, где кегль ушёл в 14.
- Сборка часто > 18 МБ: всегда `python3 shrink.py in.pptx out.pptx 18.5` (крупные непрозрачные PNG → JPEG q92), иначе файл не запишется в папку.
- Положить результат в папку «Новые 5 история» (для 6 класса — «новые 6 история»).
- Сообщить пользователю тремя списками: что перенесено дословно, какие слайды заменены слайдами шаблона, где нужны ручные правки.

## Если в старом шаблоне появилась новая декорация
Декоративные картинки старого шаблона отсекаются по хэшу (`DECOR_SKIP` в engine.py); одноцветные картинки-заглушки (белые/цветные прямоугольники) отсекаются автоматически (`is_flat`). Если на контакт-листе видны лишние лисы, уголки, полоски, — посчитать хэши картинок по всем слайдам (часто повторяющиеся и прижатые к краю слайда) и дописать в `DECOR_SKIP`.

## Если пользователь вернул правленые файлы
Сравнить свою сборку с его версией, как в разборе 6.4, и дописать новые правила в чек-лист. Если правило можно автоматизировать, поправить конвертер и перезаписать его в проект.
